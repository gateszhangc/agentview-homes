Quick Start

You can run AgentView as a desktop bundle, a lightweight CLI, or a local web server. Pick the path that fits how you work; all modes read the same on-disk session formats.

Desktop (recommended)

Install the desktop build for your platform. The app ships with an embedded UI, automatic updates, and the same indexing engine used by the CLI.

CLI & local server

Start a local server to browse sessions in your browser, run non-interactive reports, or pipe summaries into your own tooling.

The desktop app and CLI share the same data directory under your user profile, so you can mix both workflows without duplicating imports.

Fast token usage and cost reports

When your history grows into thousands of sessions, ad-hoc scripts slow down. AgentView keeps a pre-indexed database so daily rollups return in well under a second, even on large corpora.

Reports read the same normalized message records that power search and analytics, so numbers stay aligned with what you see in the transcript viewer.

What it does

AgentView ingests the JSONL and sidecar files your coding agents emit, normalizes them into a structured timeline, and layers full-text search and analytics on top—without sending your transcripts to a hosted SaaS by default.

Browse sessions

Scroll chronologically through every session, per workspace or across machines. Expand tool calls, thinking blocks, and file edits inline so you can reconstruct how a change actually landed.

Search everything

Full-text search across user prompts, assistant replies, stderr snippets, and tool payloads. Jump from a hit straight into surrounding context.

Session analytics

Heatmaps, tool-frequency charts, and per-project velocity help you see whether agents are accelerating delivery or getting stuck in retry loops.

AI-assisted insights

Optional summarization turns long threads into short digests: what shipped, what broke, and what still needs a human decision—scoped to a repo or your entire corpus.

Multi-agent support

Parsers cover the major coding-agent formats. Session roots are discovered automatically so you spend less time wiring paths and more time reviewing outcomes.

Import chat exports

Bring in archived web-chat exports when you need a single place that mixes browser conversations with local agent transcripts.

Runs locally

A compact SQLite database holds structured rows and FTS indexes. The embedded UI talks to a small REST surface with server-sent events for live refresh while files change on disk.

How it works

Watch configured session directories, parse each agent’s JSONL stream, normalize messages and tool spans, then persist to SQLite with FTS5 for search. The SPA issues queries over HTTP and subscribes to change notifications when new lines append.

  1. 1 File watcher notices new or updated session files.
  2. 2 Format-specific parsers map records into a shared schema.
  3. 3 Indexes update incrementally so search stays hot.
  4. 4 The UI renders threads, charts, and exports from the same store.

For teams that want a shared view, an optional database sync path can replicate summaries and redacted metadata to a central server while keeping raw transcripts at the edge—configure retention and fields explicitly before turning it on.

Who it is for

Staff engineers reviewing agent-driven refactors, platform teams auditing tool usage, and solo developers who simply want a fast, trustworthy archive of what the model tried yesterday. If your workflow already produces machine-readable logs, AgentView is the lens.
